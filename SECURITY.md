# Security Policy

## Supported Versions

Only the latest release of Anastasia receives security fixes. Updates ship
through the in-app updater and https://anastasia.invalid.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting:
https://github.com/cowboyshibuya/anastasia/security/advisories/new

If that doesn't work for you, email hi@egoist.dev.

Please don't open a public issue for anything you believe is
exploitable before it has been fixed. Include reproduction steps and
the Anastasia version (Anastasia → About Anastasia) you tested.
